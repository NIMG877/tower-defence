# SetAttackCombo

Absolute combo count assigned to `bae.cumbo` on `BeforeAttackEvent`.
This is an **assignment**, not an addition: the value overwrites
whatever the dispatcher or a prior component had set.

**Registered as:** `SetAttackCombo`
**Class:** `SkillSystem.Components.SetAttackCombo`
**File:** `Assets/PublicScripts/Entity-LevelPublicScripts/SkillSystem/Components/SetAttackCombo.cs`

## Parameters

| Key | Type | Default | Description |
|---|---|---|---|
| `cumbo` | Int | `1` | Absolute combo count assigned to `bae.cumbo` on `BeforeAttackEvent`. `1` = no change. |
