# AttackBase POCO 化重构方案（通用核心 + OnAttackIdle + SO 数据迁移）

## 目标与范围
- 攻击通用逻辑（计时/索敌/事件链/伤害管线/发弹）从 MonoBehaviour 迁入 POCO 子系统 `EntityAttack`（对齐 EntityStats/EntityVision 先例：Entity 构造、Entity.FixedUpdate 统一 tick）。
- `NormalAttack` 的行为成为 POCO 默认实现，组件删除，26 个 prefab 由迁移工具清理。
- 新增 `OnAttackIdle` 触发事件（攻击就绪但无目标时的原始信号，规则侧自行用条件门控）。
- 序列化数据迁 SO：新建 `AttackResources`（对齐 `AnimationResources` 模式），`EntityData.AttackResources` 引用；`BulletSpawnTransform` 改存**相对路径字符串**，运行时 `transform.Find` 解析。
- 已废弃的特种攻击功能不再参与本轮 POCO 化：不设计特种攻击适配器、变体钩子或专项兼容路径。

## 新增文件

### 1. `Assets/PublicScripts/Entity-LevelPublicScripts/EntityBehavior/EntityAttack.cs` — POCO 攻击核心
从现 AttackBase.cs 平移并去 MonoBehaviour 化：
- **8 个委托类型 + 事件**（OnAttackInterrupt/OnAttackSuccessfully/OnBeforeAttack/OnBeforeTakeDamage/OnAfterAttack/OnAfterTakeDamage/OnBeforeTargetSelect/OnAfterTargetSelect）改为嵌套于 `EntityAttack`；**新增 `OperationsOnAttackIdle` 委托 + `OnAttackIdle` 事件**。
- 嵌套 `AttackEffectData` 结构保留原字段形态（BulletData/BulletSpawnTransform/AttackEffect），供 NormalAttack 数据迁移与运行时默认攻击复用。
- 成员平移：`Tick(dt)`（原 FixedUpdate，逻辑不变）、`PreWarm/Initialize/Dormancy`、`TryToAttack`（虚方法，默认体=现 NormalAttack 实现）、`AttackSingleTargetOperation`（虚方法，默认体=现 NormalAttack 实现）、`AttackByAnimation`、`HitTargetAndSplash`/`SplashAroundTarget`/`HitTarget`/`FireBullet`、`AttackTargetSelect`、`ForceResetAttack`、`Set/ResetAttackEffectData`、`TryGetExtraEffectData`、`AttributesCaculateFirst`（VisionRange→AttackRangeS）、DamageType/TargetPriority 字段。
- **OnAttackIdle 触发点**：Tick 的 else 分支重构为「状态门通过 → 索敌 → `targets.Length==0` 则 `OnAttackIdle?.Invoke()` → TryToAttack」。语义=「攻击就绪（计时到点、非 Start/Cast/Die）且无目标」，每物理帧可重复（与 TickEvent 同范式，规则侧用条件门控）。
- **SO 数据装载**：PreWarm 时若 `EntityData.AttackResources != null` → Default/ExtraEffects 逐条转换（路径字符串→`root.transform.Find(path)` 解析出生点，解析失败 LogWarning 并置 null），写入 `_defaultEffectData`/`_extraEffectDatas`。
- `_configured` 门：SO 未配置时 TryToAttack 直接 false（保持今天「无攻击模块实体被 ForceAttack 时静默跳过」的行为）。

### 2. `Assets/PublicScripts/GameData/Attack/AttackResources.cs` — 攻击数据 SO
`[CreateAssetMenu("TD/Entity/Attack Resources")]`，对齐 AnimationResources：
```csharp
[Serializable] public class AttackEffectDataAsset {
    public BulletData BulletData;
    public string BulletSpawnPath;   // 相对实体根的路径，如 "Spine/Proxy/F_Muzzle"；空=近战/无出生点
    public GameObject AttackEffect;
}
public AttackEffectDataAsset Default;
public List<AttackEffectDataAsset> ExtraEffects = new();
```

### 3. `Assets/DataTools/AttackDataMigration.cs` — 一次性编辑器迁移工具（菜单 Tools/Static Data/…）
- 扫描所有挂 NormalAttack（按脚本 GUID）的 prefab；已废弃的特种攻击组件不参与迁移。
- 读取 `_attackEffectData0` + `_extraEffectDatas`：BulletData/AttackEffect 资产引用原样拷贝；`BulletSpawnTransform` 向上回溯到 prefab 根生成相对路径字符串。
- 在约定路径 `Assets/Resources/GameDatas/Attacks/{EntityID}` 创建/覆盖 AttackResources SO。
- 在 EntityDataCollection.asset 中按 `EntityData.Prefab == 该prefab` 匹配条目，赋值 `AttackResources` 字段（SerializedObject 写入+保存）。
- 从 prefab 移除 NormalAttack 组件并保存；输出迁移报告（成功/跳过/失败清单）。
- 幂等：重复运行安全。

## 重写：`AttackScripts/AttackBase.cs` → 迁移过渡壳
- 保留：类名 `AttackBase`、脚本文件 GUID（prefab 引用不断）、`MonoBehaviour, IPoolOperation`、`[SerializeField]` 字段（`_attackEffectData0`/`_extraEffectDatas`，类型改为引用 `EntityAttack.AttackEffectData`，YAML 兼容）。
- 删除：FixedUpdate、全部引擎逻辑（已平移至 EntityAttack）。
- PreWarm：仅把自身序列化攻击数据推入 `Entity.Attack` 核心，作为 NormalAttack prefab 迁移前的过渡数据来源。
- Initialize/Dormancy（IPoolOperation）：不转发核心生命周期；核心由 Entity 驱动，避免双重调用。
- 保留 protected 转发壳（`_thisEntity`、`FireBullet`、`HitTargetAndSplash` 等）供子类 override 体使用，子类方法体几乎零改动。
- NormalAttack.cs 删除（含 .meta）。

## 行为变化说明（有意为之）
1. **tick 顺序确定化**：今日常规下 Entity 与 AttackBase 的 FixedUpdate 先后未定义（项目无脚本执行顺序设置），索敌可能用上一帧视野；重构后攻击 tick 固定在 `Vision.Refresh` 之后——严格更优。
2. 事件顺序不变：Dormancy 清事件仍先于技能侧退订；Initialize 时序核对新旧等价（核心 Initialize 只重置计时/DamageType/TargetPriority，无 Buff/动画依赖）。
